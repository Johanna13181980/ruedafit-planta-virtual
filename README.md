# RuedaFit — planta virtual 3D

Simulación inicial RuedaFit y prueba de publicación de realvirtual WEB Community.

- `index.html`: simulador inicial de RuedaFit.
- `ruedafit-realvirtual.html`: acceso al visualizador.
- `modelos/ruedafit_planta.glb`: modelo de la planta.
- `.github/workflows/publicar-realvirtual.yml`: compilación y despliegue automático de realvirtual.

**Estado:** integración en pruebas. El modelo y la lógica de eventos aún no están sincronizados con realvirtual.
